# Next.js SSG(Static Site Generation)

SSG는 **Static Site Generation**의 약자로, 빌드 시점에 웹 페이지를 미리 HTML 형태로 생성하는 방식임. Next.js에서 지원하며, `getStaticProps` 함수를 사용해 데이터를 가져오고 이를 기반으로 정적 페이지를 생성함. 생성된 페이지는 CDN을 통해 전 세계 사용자에게 빠르게 제공 가능함.

---

## 1. SSG의 특징

- **빌드 시점 데이터 패칭**: 데이터를 빌드 시점에 미리 가져와 HTML로 변환함.
- **정적 파일 제공**: 사용자가 요청하면 미리 만들어진 정적 파일을 그대로 반환함.
- **Incremental Static Regeneration(ISR)**: 특정 페이지를 일정 주기로 갱신할 수 있는 기능을 제공함.

---

## 2. SSG의 장점

1. **빠른 로딩 속도**  
   정적 파일로 제공되기 때문에 페이지 로딩 속도가 매우 빠름.

2. **CDN 활용 용이**  
   정적 파일을 CDN에 배포하여 전 세계 어디서나 동일한 속도로 접근 가능함.

3. **서버 부하 감소**  
   사전 생성된 파일을 제공하기 때문에 서버가 요청을 처리할 때 리소스 소모가 적음.

4. **SEO에 유리함**  
   빌드 시점에 완성된 HTML을 제공하므로 검색 엔진 크롤러가 페이지를 쉽게 인덱싱할 수 있음.

---

## 3. SSG의 단점

1. **빌드 시간 증가**  
   페이지 수와 데이터가 많아질수록 빌드 시간이 길어짐.

2. **실시간 데이터 반영 어려움**  
   배포 후 변경된 데이터를 바로 반영하기 힘들며, ISR로 이를 부분적으로 해결 가능함.

3. **빌드 후 데이터 변경 시 재배포 필요**  
   데이터가 변경되면 다시 빌드와 배포 과정을 거쳐야 함.

---

## 4. SSR(Server Side Rendering)과의 비교

**SSR(Server Side Rendering)**은 사용자가 페이지를 요청할 때마다 서버에서 데이터를 조회하고 HTML을 생성하여 반환하는 방식임. Next.js에서는 `getServerSideProps`를 사용해 구현함.

| 구분                 | SSG                                                                 | SSR                                                             |
|---------------------|---------------------------------------------------------------------|-----------------------------------------------------------------|
| 페이지 생성 시점    | 빌드 시점에 미리 생성됨                                             | 요청 시점에 동적으로 생성됨                                     |
| 빌드 시간           | 페이지 수와 데이터 양이 많을수록 늘어남                             | 빌드 시점에 정적 HTML을 생성하지 않으므로 상대적으로 짧음       |
| 서버 부하           | 정적 파일 제공 → 서버 부하가 낮음                                   | 요청마다 HTML을 생성해야 해서 서버 부하가 높음                 |
| 데이터 최신화       | 배포 시점 데이터로 고정되며 ISR로 갱신 가능함                       | 요청 시마다 최신 데이터로 페이지를 생성함                      |
| 로딩 속도           | 사전 생성된 파일 제공 → 빠름                                        | 서버 처리를 거친 뒤 HTML 반환 → 상대적으로 느릴 수 있음        |
| SEO 효과           | 사전 생성된 HTML 제공 → 검색 엔진에 유리함                         | 동적으로 생성되지만 완성된 HTML을 반환하므로 SEO에 유리함      |

---

SSG는 정적 콘텐츠가 주를 이루는 사이트(블로그, 문서 사이트 등)에 적합하며, SSR은 사용자별 맞춤 데이터를 필요로 하는 동적 콘텐츠 사이트에 적합함.
